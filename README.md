# 정류장에서 다시 재는 저상버스

저상버스 정책의 성과는 **보유율(%)** 로 보고된다. 그런데 휠체어를 탄 사람은 차량을
고르지 못한다. 정류장에 서서 오는 버스를 받을 뿐이다. 그래서 서울 시내버스 저상버스를
차량이 아니라 **정류장 단위**로 다시 쟀다.

「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」(한겨레 · 재단법인 숲과나눔)
제출용 분석 코드다.

## 무엇을 재는가

정류장 하나에 여러 노선이 선다. 노선 `r` 이 `h_r` 분마다 오고 그 노선의 저상버스
보유율이 `p_r` 이면, 그 정류장에 **탈 수 있는 버스**가 오는 빈도는 `Σ p_r / h_r` 이다.
그 역수를 **저상버스 유효 배차간격**이라 부른다.

```
전체 유효 배차  h_all = 1 / Σ (1 / h_r)
저상 유효 배차  h_lf  = 1 / Σ (p_r / h_r)
배수 = h_lf / h_all          1 이면 다른 승객과 똑같이 기다린다는 뜻
```

## 나온 것

| | |
|---|---|
| 서울 시내버스 저상버스 보유율 | **77.3%** (저상 5,154 / 인가 6,667대, 328개 노선) |
| 노선별 보유율 | 0% 28개 · 50% 미만 67개 · 100% 86개 (중앙 81%) |
| 정류장 저상 유효 배차(출퇴근) | 중앙 **3.2분** · 상위 10% 12.0분 (전체 버스는 2.4분) |
| 30분을 넘거나 저상이 아예 서지 않는 정류장 | **200곳** (5,653곳의 3.5%) |
| 그 가운데 노선이 하나뿐인 정류장 | **188곳(94%)** |
| 같은 운수회사 안에서 저상차를 옮기면 | **20대**로 200곳 → 109곳 |
| 회사 경계를 넘어 교환까지 허용하면 | **173대**로 200곳 → 23곳 |

## 셈에 깔린 가정

- 저상차는 노선의 차량 운용에 섞여 돌므로, 그 노선의 한 번의 도착이 저상일 확률을
  보유율 `p_r` 로 둔다. 실제로는 특정 시간대에 몰릴 수 있다.
- 배차간격은 인가현황의 최소배차(혼잡 시간대)와 최대배차(한산 시간대)를 따로 쓴다.
- 저상 자료(2025-04)와 노선·정류소 자료(2026-09) 사이에 시차가 있다. 두 자료에 모두
  있는 328개 노선만 쓰고, 한쪽에만 있는 노선은 분자와 분모 양쪽에서 뺀다.
- 정류장마다 **집계된 노선의 운행 빈도가 전체의 70% 이상**일 때만 셈에 넣는다.
- 서울 정류소 고유번호 앞 세 자리가 자치구다(100 종로구 ~ 124 강동구). 서울 시내버스가
  경기 땅을 지나기도 해서, 이 자리로 서울 안 정류장만 골랐다.
